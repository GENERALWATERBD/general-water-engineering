# General Water & Engineering — Website Starter

A responsive, English-language corporate website for General Water & Engineering.

## Files
- `index.html` — page structure and content
- `styles.css` — responsive styling
- `script.js` — mobile navigation and email-based enquiry form

## Preview locally
Open `index.html` in a modern browser. Internet access is required for the remote photographs and Google Fonts.

## Free hosting + own domain
1. Create a GitHub account and a new public repository, for example `general-water-engineering`.
2. Upload all three website files to the repository root.
3. In repository **Settings → Pages**, choose deploy from the `main` branch and `/ (root)`, then save.
4. GitHub Pages will provide a free `github.io` URL.
5. Buy a domain from a registrar, then add it in **Settings → Pages → Custom domain**. Configure the DNS records exactly as GitHub Pages instructs and enable HTTPS when available.

Cloudflare Pages is another free static-hosting option. A custom domain normally costs money even when hosting is free.

## Before publishing
- Confirm the company phone number, address and email shown in the site.
- Replace the example/stock photographs with your own project photographs where possible.
- Add only genuine project details, certifications, client logos and testimonials.
- The enquiry form uses `mailto:` and does not store submissions. For a hosted form that submits directly from the site, connect a form service or backend.
- Check that the chosen domain is available before purchasing.
